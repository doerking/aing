这些脚本证明**门禁会红**（防橡皮图章），任何院子均可复跑：锚全部动态取自
`path.resolve(__dirname,'..','..')`，不含机器路径；注入后**先断言注入真的生效**再判门禁；
结束按字节还原（含进程异常退出的 exit 兜底还原）。全部只经 `VD_ONLY` 跑单门，不写验收登记。
