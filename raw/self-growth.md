# 自成长核心路线

## 设计哲学

知识库不应是静态仓库，而应具备自我成长能力：

- **自我感知**：知道自己的状态
- **自我诊断**：知道哪里有问题
- **自我修复**：知道怎么修
- **自我优化**：知道怎么更好

## 核心能力

### 1. 知识缺口检测 (Gap Detector)

5维缺口扫描：
- 孤立实体（无链接）
- 稀薄领域（同类型 <5%）
- 停滞知识（>14天未更新）
- 未向量化（无索引）
- 空内容（内容过少）

### 2. 自动修复 (Auto Fix)

基于 KESPI 维度诊断：
- 根因分析 → 精准开方
- 预期收益评估
- 执行代价估算

### 3. 遗忘曲线 (Forgetting Curve)

艾宾浩斯遗忘曲线知识复习：
- 新知识保护期
- 复习间隔递增
- 记忆强度衰减模型

### 4. 自适应调参 (Auto Tuner)

根据代谢效果自动调整：
- 代谢频率
- 压缩阈值
- 剪枝周期
- KESPI 权重

## 成长循环

```
感知 → 诊断 → 决策 → 执行 → 评估 → 调参 → 感知
```

## 与 KESPI 的关系

KESPI 是自成长的"感知-决策桥梁"：
- 8 维评分量化知识质量
- 维度级根因分析定位问题
- 精准干预动作附带预期收益
- 闭环调参确保长期优化
