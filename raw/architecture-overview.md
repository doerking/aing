# aing 双脑架构总览

## 架构概述

aing 双脑架构是一种创新的知识管理系统，模拟人脑的双重处理机制：

- **秩序脑 (Order Brain)**：负责知识的编译、存储和版本管理
- **生长脑 (Growth Brain)**：负责知识的发芽、授粉、压缩和进化

## 核心层次

1. **意识神经层**：感知 → 路由 → 输出
2. **MoA-Hier 蜂群调度**：多 Agent 协作
3. **双脑架构层**：秩序脑 × 生长脑
4. **基础运行时**：Markdown + Node.js + Git + SQLite

## 秩序脑功能

- 编译引擎：raw/*.md → wiki/entities/*.md
- 实体管理：CRUD + 类型分类
- 链接管理：实体间关联关系
- 版本控制：Git 集成

## 生长脑功能

- 发芽 (Sprout)：发现新关联
- 授粉 (Pollinate)：跨域知识融合
- 压缩 (Compress)：低频知识归档到芥子库
- 回炉 (Recycle)：芥子→元知识微粒，再次进入代谢
- 剪枝 (Prune)：过期知识清理

## 关键指标

- KESPI 八维质量评分体系
- 768 维向量语义检索
- 自动化代谢流水线
- 意识神经三层架构
- 进化回路：回炉闭环 + 学习梯度（详见 evolution-loop.md）

## 数据流

```
原始资料 → 编译 → 实体库 → 代谢循环 → 质量评估 → 决策
                ↑                          ↓
                └──────── 反馈调整 ←───────┘

回炉支路：实体 → 剪断 → 芥子 → 回炉 → 元知识微粒 → 再发芽
```
