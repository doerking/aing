# data/lexicon · 词典登记（SPEC-7.1 AC-9 / AC-13）

本目录是派生词生成器（`src/derive.js`）的**唯一**词典来源。生成器纯本地、确定性、无网络调用；
新增或替换词典必须在本文件登记**用途 / 出处 / 许可**，否则 `test-7.1q-lexicon-provenance` 会红。

| 文件 | 用途 | 出处 | 许可 | 更新 |
|---|---|---|---|---|
| `zh-variant.json` | 简→繁字级基础表（`s2t`）。只收起码点 1:1 且无歧义的字；多音多义字（后/後、复/復、尽/盡）不收，留给词级词典 | 人工整理起步集（本仓自建） | 无第三方许可约束；随本仓发布 | 2026-11-17 |
| `yue-morph.json` | 粤语词素词典：词条 → 词素拆分 + 普通话对照（`entries`）。只收确定性、无语境的常用词 | 人工整理起步集（本仓自建） | 无第三方许可约束；随本仓发布 | 2026-11-17 |
| `zh-synonym.json` | 同义/别名组（`groups`）：同组词互相可查，只进**查询扩展**、不进行检索词面 | 人工整理（领域词 + 口语对照） | 无第三方许可约束；随本仓发布 | 2026-11-17 |

## 引入外部词典时的规矩

- 只收**词表/字表数据**，不引在线服务、不引原生依赖（OpenCC 采其词典数据，`opencc-js` 的许可与出处须在此登记）。
- 候选来源与许可：words.hk（5.3 万条，商用需授权）、HKCanCor（CC BY 4.0）、rime-cantonese、同义词词林、HowNet/OpenHowNet。
- 登记内容至少写清：文件、用途、出处 URL 或版本号、许可类型、是否允许随包发布。
- 每个文件的 `_meta.purpose` / `_meta.license` / `_meta.updated` 必须与上表一致。
