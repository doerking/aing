# 折叠基础

所有作品都建立在少数几个基础形之上。

## 两大基础形

- **方基础（Square Base）**：[[demo-paper-crane]] 的起点。
- **鱼基础（Fish Base）**：多用于花瓣类造型。

## 基本折法

| 名称 | 动作 |
|------|------|
| 谷折 | 纸向自己折 |
| 山折 | 纸向背面折 |
| 兔耳折 | 两谷夹一山收尖 |

压线用指尖不够实，推荐骨笔。纸张受潮后韧性变化很大，涉及定型的作品请看 [[demo-wet-folding]]。

制图符号按 [[demo-standard-symbols]] 阅读图解。
