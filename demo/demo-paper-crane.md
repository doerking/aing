# 千纸鹤（Orizuru）

千纸鹤是折纸最经典的作品，也是云杉折纸社的招牌。

## 折叠要点

1. 正方形纸，先折出两条对角线谷折。
2. 按 [[demo-folding-basics]] 的「方基础」起形。
3. 收翼时注意保持对称，歪斜多因第 3 步压线不实。
4. 想要造型饱满可改用 [[demo-wet-folding]]（湿折法）。

## 常见问题

- 翅膀下垂：纸太薄，建议 70g 以上。
- 头部折角断裂：压线过重，改用骨笔。

符号含义见 [[demo-standard-symbols]]。
