# 质量门禁规范

## KESPI 五维评估

| 维度 | 说明 | 阈值 |
|---|---|---|
| K - Freshness | 内容新鲜度 | ≥ 0.7 |
| E - Relevance | 相关性 | ≥ 0.7 |
| S - Originality | 原创性 | ≥ 0.6 |
| P - Consistency | 一致性 | ≥ 0.8 |
| I - Provability | 可验证性 | ≥ 0.7 |
| Overall | 综合评分 | ≥ 0.75 |

## 质量门禁流程

1. 编译后自动运行 KESPI 检查
2. 低于阈值的实体标记为"待优化"
3. 连续 3 次不通过则进入压缩队列
4. 90 天不活跃自动剪枝
