# SPEC-6.34 · 六段由实体事实抽出

> **一句话**：P1 接单方交的六段原本是同一张恒定文案——换哪个实体都写一样的话，覆盖率满分但没有一句是本实体的事实。本轮把模板改成「骨架 + 事实槽」，每段从实体自己的 turns / 工具 / 校准里抽。

## 一、病证

| 实体 | 修前六段 | 修后六段 |
|---|---|---|
| A（有工具、无子agent） | 与 B 逐字相同 | 场景含 A 首轮输入；手段列 A 的工具名；编排如实写「无子agent」 |
| B（无工具、有校准） | 与 A 逐字相同 | 场景含 B 首轮输入；手段写「无工具调用」；校准列 B 的校准条目 |

恒定文案有两个后果：**读数失真**（六段齐但零信息，kq 照样满分）；**不可审计**（回单无法回溯到本实体的证据）。

## 二、改法（`externalPartNarrative`）

按实体 content 的六段叙事 JSON 取料：

| 段 | 取材 | 无证据时 |
|---|---|---|
| 场景（触发） | 单号 + 维度 + 轮数 + 首轮用户输入片段 | 写「首轮无用户输入」并说明轮数 |
| 思维（能力内核） | turns[].thinking 首片段 | 写「本单元无显式推理块」 |
| 手段（工具执行） | turns[].tools 中非子agent 的工具名与参数摘要 | 写「本单元无工具调用」 |
| 编排（子agent） | turns[].tools 中子agent 类工具 | 写「本单元无子agent」 |
| 产出 | turns[].output 首片段 | 写「本单元无文本产出」 |
| 会话级校准 | calibrations[].summary | 写「本单元无会话级校准记录」 |

- 有证据的段拼事实 + 一句说明；无证据的段**只写声明，不填充**——短于 20 字就不算有效段（6.31），覆盖率如实下降。
- 回单 `facts` 记录抽取来源（第几轮、哪类证据），供审计回溯。

## 三、Acceptance Criteria

| # | 判据 |
|---|---|
| AC-1 | 同一实体两次回单内容相同（纯读、可复现） |
| AC-2 | 两个不同实体回单显著不同，且各自含自身事实（首轮输入 / 工具名 / 校准） |
| AC-3 | 无子agent 的实体，编排段为声明且不含他实体事实 |
| AC-4 | 回单 facts 写明抽取来源 |
| AC-5 | 轨迹完整的薄实体走完 E2E：写回后 kq ≥ 0.5 转 verified |
| AC-6 | 外部件仍不写库（前后快照一致） |

## 四、边界

- 仍是**规则抽取**，不是模型生成：不做语义改写、不补结论。
- 抽取失败（content 非叙事 JSON）→ 返回 null，不编造。
- 无证据段的声明保留在 markdown 里（可读），但覆盖率如实记 0。

## 五、仍开着的

1. 「每段要有多少料才算够」仍是固定 20 字——按实体能力面浮动（有工具才必填手段段）是下一个口径决定，要数据支撑。
2. 真实模型接单时，抽取结果可作为 prompt 的事实底稿；模型改写质量未验。
