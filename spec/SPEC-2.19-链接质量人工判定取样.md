# SPEC-2.19 · 链接质量人工判定取样（假边率 / 二跳污染率）

> 状态：实装（2026-11-17）
> 上游：SPEC-1.6（连线）、SPEC-2.11（hub 裁剪）、`docs/Engineering/EMBEDDING-BENCH-2026-11-16.md` §五
> 定位：**工具先行**。这两个指标要人工判定才成立，本件只做取样与计分，不出自动结论。

---

## 一、为什么单列一件

基准文档的记录表里「假边率 / 二跳污染率」长期标「未测」，原因是需要链接构建器与人工判定样本。这两项测的是**边对不对**，不是排序好不好，任何自动代理数（负例命中率之类）冒充都不算。

所以本件只交付两样：**可复读的取样单** + **只认人工填写的计分器**。样本不自动判、比率不自评、分母缺了就拒算。

## 二、取样（`tools/link-sample.js`）

- 只读：只 `SELECT`，不开写路径，不建表不落盘。
- 两种样本：
  - `--kind edges`：活跃边（`links.invalid_at IS NULL`）单条样本，判「这条边是否成立」。
  - `--kind twohop`：两跳三元组 `A—B—C`（两条活跃边、`A≠C`、且 `A—C` 之间无活跃边），判「A、C 该不该直接连」。
- 确定性：按 `sha1(source_id + "\u0000" + target_id)`（两跳用 `A|B|C`）升序取前 N，同库同参数两次产出逐字一致。
- 可判定性：两端标题走 `conv-text.readableTopic`（与 memo / predict 同源），markdown 会话不至于是个时间戳。
- 输出：markdown 表，末尾附「判定」空列填 `?`；两跳表两列 `判定`（`应连` / `不应连` / `存疑`）。
- 参数：`--db <path>`（必填，建议副本）、`--kind edges|twohop`（默认 edges）、`--n <int>`（默认 20）、`--out <file>`（缺省打到 stdout）。

## 三、计分（`tools/judge-score.js`）

- 输入：已填写的人工判定单。
- **拒收**：任何 `?` 仍在（未判完）→ 退出码非 0，逐行列出未判序号；不出一半的数。
- 判值：边样本 `真` / `假` / `存疑`；两跳样本 `应连` / `不应连` / `存疑`。其它值视为格式错，同样拒收。
- 计算：`假边率 = 假 / (真 + 假)`，`二跳污染率 = 不应连 / (应连 + 不应连)`；`存疑` 单列不计入分母；分母为 0 时输出「样本不足」，不写 0%。
- 输出一行结论 + 计数明细（真/假/存疑），可 `--json`。
- 不碰数据库，不写任何状态。

## 四、验收（`test/test-2.19-link-sample.js`）

| AC | 断言 |
|---|---|
| AC-1 | 同库同参数跑两次，取样单逐字一致（确定性） |
| AC-2 | 取样与判分全程只读：跑前后各表行数不变 |
| AC-3 | 表头列齐（`#` / `边` / `A` / `B` / `关系` / `强度` / `判定`），行数 = min(n, 候选数)，标题不是时间戳 |
| AC-4 | 两跳样本只出 `A≠C` 且 `A—C` 无活跃边的三元组 |
| AC-5 | 有 `?` 未填 → 判分器退出码非 0 并点名未判行 |
| AC-6 | 填好后比率正确（4 行：假 1 / 真 2 / 存疑 1 → 假边率 1/3，存疑单列不计分母）；格式错值同样拒收 |

## 五、Non-Goals

- 不自动判定任何一条边（无模型、无启发式打分）。
- 不改发布默认、不改 hub 裁剪阈值：比率只作人工读数，判据变动另行裁定。
- 不做抽样统计推断（置信区间等）：样本就是样本。

## 六、依赖

- 上游：`src/conv-text.js`（标题读法）、`links` / `entities` 表。
- 消费者：人（判定表）、基准文档 §五（人工读数回填）。
