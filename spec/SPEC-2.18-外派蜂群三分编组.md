# SPEC-2.18 · 外派蜂群（采集面 / 三分编组）

> 外派是「派出去采集」，不是「多开几个内成员」。
> **粒子**是本体：轻、可弃、可量产；**派单框架**加载在粒子上：背景 + 命题 + 轨迹口径 + 输出 schema。
> 没有框架的粒子是盲的；没有粒子的框架是空的。

---

## 〇、两面边界（先于一切）

| 面 | 主体 | 触发源 | 载体 | 生命周期 |
|---|---|---|---|---|
| **守内面**（自维护） | 见 SPEC-2.14 / 2.17（**两套口径并存，待裁**，本件不裁） | 系统健康读数 | 包内 | 常驻 |
| **对外采集面**（本件） | 宿主运行时粒子（subagent） | 用户工单 | **宿主运行时，不在本包** | 完即销毁 |

四条边界：

1. 守内面不接对外工单；本件只管对外采集。
2. 包内资产不装宿主通用面；宿主没装属正常，不构成缺口。
3. **对外采集与包无代码接线**：spawn 与执行在宿主面，包内不提供 spawn 执行器。
4. 两面互不桥接。

> **待裁（另案）**：守内面在 v2 是 SPEC-2.14/2.17 的新五组件，还是内部总设定里的旧五角色。本件不裁。
> **待裁（另案）**：包内 `src/dispatch-swarm.js` 若保留，只能定位为「派单底版校验 + 攻果门校验」纯函数，不做 spawn；去留随上一条一并定。

---

## 一、目标

1. 一次外派 = 一个命题 + 一套框架 + N 粒，产出的只有**过了门的攻果**。
2. 采集只做三件：搜资料 → 看资料 → 按用户要求定厚度。
3. 全程可审计：轨迹留痕、来源分级、交叉验证、自评，缺一不发布。
4. 用完即弃：粒子交料即销毁，不囤积、不继承上下文。

---

## 二、行为（spec 即契约）

### 2.0 职责边界：只做采集

- 采集三件，顺序写死：**搜资料 → 看资料 → 定厚度**。
- 不裁决、不出结论、不代读；裁决与落库归场域，对外交付由派发人定。

### 2.1 厚度由用户要求定（2026-11-17 追加）

- 派单命题必须写明**厚度要求**：这单要采多厚（覆盖面 / 深度 / 源数量级）。
- 粒子在厚度内取材，不自定、不代定；交付时自报 `{required, achieved, met}`。
- 不达标照交，由派发人决定是否再派——**不自动加码**。

### 2.2 粒子与框架

- 粒子＝宿主 spawn 的 subagent：真并行、真隔离、完即销毁。
- 派单框架＝粒子 prompt 必载四项：**背景、命题、轨迹口径、输出 schema**；缺项视同未载，不得派出。
- 同一框架可 spawn N 粒，数量按任务复杂度，无硬上限。
- 粒与粒之间**正面不重叠**：每粒负责不同的面，不重复采同一处。

### 2.3 七步派单流程（顺序写死）

1. **立命题**：要什么 + 怎么算对（先定判据再派人）
2. **选路径**：单点查证 / 交叉验证 / 多源对比 / 广扫
3. **载框架**：四项全载，禁阉割版
4. **spawn 粒子**：每粒一个 subagent，prompt 含框架四项
5. **收攻果**：回报先过门（来源分级 + 交叉验证 + 自评）
6. **聚合**：**不等齐**，有料就合；矛盾原样呈现，不强行收敛
7. **销毁**：粒子交料即弃，不留状态

### 2.4 轨迹口径（质量底线）

- 每点轨迹只写**事实 + 来源指针**，**拦结论全文**。
- 每点轨迹 **≤ 12 条**。
- 禁止复制全文、禁止代读结论——粒子的本分是指路，不是代读。
- 判例：`「市占 23%（出处：年报 P42）」` 合格；`「这家公司很强」` 不合格（无指针、无事实）。

### 2.5 来源分级与交叉验证

| 级 | 判据 |
|---|---|
| 高 | 一手官方 / 原始文档 / 可复现实验 / 权威库 |
| 中 | 可靠二手 / 有署名分析 / 行业报告 |
| 低 | 匿名 / 无出处 / 推测 |
| 未分级 | **一律归残渣**，不能当情报用 |

- 高置信结论需 **≥2 个独立源**交叉；同一作者讲两遍不算互证。
- 重要结论至少两粒走**不同路径**交叉；单源结论只能当线索，不能当攻果。
- 掩护位抓到矛盾即打回重采。

### 2.6 攻果发布门（四件齐一）

事实 + 证据（出处） + 来源分级 + 自评，**缺一不发布**。

- 未过门的料 = 残渣，不能喂用户。
- 矛盾未解 → 原样呈现，不做强行收敛。

### 2.7 基线门

- **无基线不编队**：先有对照 / 已知答案 / 可复现基准。
- **打不过基线就砍**：不自我安慰「有产出就算」。
- 基线随命题一起写，不做事后追认。

### 2.8 编队

- **一个单元 = 3 粒**；**一个班 = 3 单元**（合计 9 粒）。
- **1 前出、2 展开，禁同刻**：1 单元先出，其余按波次待命，不 9 粒同刻盲跑。
- **正面不重叠**：每粒负责不同的面。
- **编组规模参考不外显**：内部参谋使用，不上界面、面板、脚注。
- 波次：①抽取单元 3 粒 → 返料后 ②深挖 → ③交叉；不等齐，有单就派。

### 2.9 两权分离

- **拍板权独归拍板人（owner）**；派发人只做立命题、选路径、载框架、spawn、收攻果、聚合、销毁。
- **班长无调兵权**（现场协调岗，不占粒子编制）。
- **单元长无调度权**（粒内执行）。
- **粒子只执行，不决策**。

### 2.10 推进：批内不等回，批间等用户

- **批内**：新单即派，不等旧单返料；不批量、不排队、不攒齐。
- **批间**：只有**用户说继续**才派下一批；未说即停派，不自动续单、不按时间表续派。

### 2.11 收口：交料即消逝、零写权

- 收口交四样：**料 + 厚度达标情况 + 轨迹 + 标签**（标签至少含 `unit/ticket/outcome`）。
- 缺一 → 拒收，粒子保持在工作状态。
- 收口成功 → 粒子销毁，残渣回流；**不继承上下文**，下一单从零底版起。
- 外派对知识库**零写权**；任何写意图直接拒绝。残渣如何落库归场域决定。

### 2.12 无熔断

- 不设失败阈值、停派窗口、半开探测。
- 单点损伤按点位补位继续（点—线—面连续性），不因次数停派。
- 是否继续采集由用户闸（2.10 批间）决定，不由失败计数决定。

### 2.13 禁虚报（三布尔）

三个「有」**分开报**，不得合并：

| 布尔 | 含义 |
|---|---|
| `swarmInstalled` | 机器上装了 |
| `inRuntimeSurface` | 本运行时加载了 |
| `bundledInPackage` | 包内自带 |

- 只有 `inRuntimeSurface = true` 才许标 `mode: swarm-skill`；否则只能是 `mode: inline-degraded`（内联扮演自办）。
- **禁止假称能派**：拿 `installed` 当能派依据即违规。

### 2.14 粒子三类（禁裸派，每类一个模板）

| 类 | 用途 | 必带 |
|---|---|---|
| **A 普通粒子** | 抽取 / 查证 / 深挖 | 命题 + 判据 + 轨迹口径 + 来源分级 + 交叉验证 + 发布门 + 基线门 + 两权分离 + 岗位卡 + 回报 schema |
| **B 掩护位粒子** | **只抓矛盾**，不找新料 | 逐条比对两个以上来源的同一事实（数值 / 日期 / 口径 / 因果链）；查「单源当攻果」；查「未分级当情报」 |
| **C 抽查粒子** | 质量抽检，非全查 | 抽 N 条核三样：①事实与出处是否一致 ②分级是否合理 ③有无过度解读；报合格率 X/N |

- **每批至少 1 粒掩护位**。实证：内部首战（2026-11-03）有专职挑刺者，质量高一档，且真拦下过共识。
- 三类模板全文载入，禁阉割版。

### 2.15 掩护位三条铁律

1. **只抓不修**：只标红「此处矛盾 / 单源 / 未分级」，不负责改料。
2. **两边都报**：矛盾两边原文与出处都贴，不自判谁对。
3. **红即回炉**：抓到红，该攻果不准过门，回去重采。

### 2.16 回报 schema 与验收判据

统一回报格式：

```
## 攻果回报
- 命题：
- 料（≤12 条）：1. <事实> ｜ 出处 ｜ 分级
- 矛盾：【有/无】<内容>
- 自评：信心 <高/中/低> ｜ 缺口 <...>
- Verdict：<PASS 过门 / FAIL 未过门 + 原因>
```

验收判据（命中即违规或返工）：

| 情形 | 判定 |
|---|---|
| 单点轨迹 > 12 条 | 超口径，返工 |
| 出现「我认为 / 总之 / 显然」类结论 | 违规 |
| 单源结论未标「线索」 | 违规 |
| 自行收敛矛盾 | 违规 |
| 无基线就派单 | 违规派单 |
| 粒子自行改命题方向或替班长下指令 | 违规 |
| 四件不齐却写 `Verdict: PASS` | 违规 |

### 2.17 失败降级阶梯（降级但不跳门）

| 情形 | 降级 |
|---|---|
| 某类粒子缺失 | 派发人按模板内联补位，终报标注降级损失 |
| 单粒产出过大（同量级 > 2000 行） | 降为单角色执行模式，拆单再派 |
| 运行时未加载外派框架（`inRuntimeSurface=false`） | `inline-degraded`：派发人内联扮演，**仍过门，不跳门** |

### 2.18 成本纪律（首战教训）

- 内部首战实测（2026-11-03，安全债单）：4 个子代理合计约 **4.6M token**，超旧预算约 15 倍。
- 因此：粒子数按复杂度而定；**不 9 粒同刻盲跑**；按波次 1 前出、2 展开；超限即降级。
- 预算按实测重定标，不沿用旧约束。

## 三、Acceptance Criteria

| # | 判据 | 检验方式 |
|---|---|---|
| AC-1 | 缺底版拒派 | 缺 workflow → 抛 `baseline-missing`，单位数不变 |
| AC-2 | 单间不互斥 | 连派两单 → 两单位同时 running，互不等待 |
| AC-3 | 收口校验 + 交接不继承 | 缺轨迹/标签/厚度 → 拒收且单位在跑；齐 → 收口解散、残渣齐；新单 `inherited` 为空 |
| AC-4 | 3 粒职责不重叠 | 角色集合恰 3 个、职责两两不同 |
| AC-5 | 零写权 | 写意图直接拒绝；无任何实体/边写入 |
| AC-6 | 缺厚度拒派 | 命题无 `thickness` → 抛 `thickness-missing`，单位数不变 |
| AC-7 | 交付自报厚度达标 | 收口必带 `thickness{required,achieved,met}`；缺 → 拒收 |
| AC-8 | 批间只认用户闸 | 同批可连派；未声明继续 → 下一批 `batch-locked`，不自动续 |
| AC-9 | 无熔断 | 连续 5 单失败后仍可派，无停派窗口、无半开 |
| AC-10 | 轨迹口径 | 单点轨迹 > 12 条 → 拒收；无来源指针的事实 → 拒收；结论全文 → 拒收 |
| AC-11 | 来源分级 | 未分级源不得进攻果；高置信结论少于 2 个独立源 → 降级为线索 |
| AC-12 | 攻果四件门 | 事实/证据/分级/自评缺一 → 不发布，归残渣 |
| AC-13 | 基线门 | 命题无基线 → 拒编队；结果打不过基线 → 砍，不发布 |
| AC-14 | 禁虚报 | `inRuntimeSurface=false` ⇒ `mode≠swarm-skill`；`=true` ⇒ `mode=swarm-skill` |
| AC-15 | 两权分离 | 班长/单元长/粒子均无调兵或拍板权；拍板只认 owner |
| AC-16 | 三类粒子模板齐 | A/B/C 各自模板字段齐；每批至少 1 粒掩护位；缺模板 → 拒派 |
| AC-17 | 掩护位铁律 | 掩护位输出必含矛盾清单 + 单源违规 + 未分级违规；只抓不修、不判谁对 |
| AC-18 | 回报 schema 与验收 | 回报五项齐；>12 条 / 结论性措辞 / 单源未标线索 / 自收敛 → 拒收 |
| AC-19 | 降级不跳门 | 运行时未加载 → `inline-degraded` 且仍过门；降级损失在终报标注 |
| AC-20 | 成本纪律 | 同刻不超一波；超限降级并报数，不静默 9 粒齐发 |

> 现状：AC-1~5 已由 `test/test-2.18-dispatch-swarm.js` 覆盖（7/7 绿）；AC-6~20 是契约，代码待补。

## 四、Non-Goals

- 不做内蜂群（2.14/2.17）；守内面口径另裁。
- 不提供 spawn 执行器（边界 3）；包内不实现宿主派工。
- 不做外派资料库与模板渲染。
- 不做守内↔对外桥接（条令：互不桥接）。
- **不做裁决**：多路候选 / 择优裁断并入场域，不迁（旧院三路编排件不移植；复杂判断仍单路直出）。
- **不做熔断**（见 2.12）。
- **不做自动续派**（见 2.10）。

## 五、契约

- `FRAMEWORK_REQUIRED = ['background', 'statement', 'trace_policy', 'output_schema']`
- `PARTICLE_CLASSES = ['normal', 'cover', 'spot-check']`（掩护位每批至少 1 粒）
- `DISPATCH_CARD = {statement, criteria, path, particles, wave, baseline, thickness}`

- 攻果 schema：`{facts:[{text, source}], sources:[{level: high|medium|low|unclassified}], crossChecks:[], selfReview}`
- 收口返回：`{unitId, ticket, thickness:{required,achieved,met}, traces, tags, residue}`
- 虚报三布尔：`{swarmInstalled, inRuntimeSurface, bundledInPackage, mode: 'swarm-skill'|'inline-degraded'}`
