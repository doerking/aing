# SPEC-6.38 · 摘录窗口滑动

> **一句话**：六段抽取原来永远从第 0 个字截，同一实体每轮回单都是同一段。现在起点按游标前后挪 ±1..±5 字——读的是同一篇原文，摘到的是不同片段。

## 一、口径

```
delta = sectionThreshold(entityId, {round}) - 20      // 0 或 ±1..±5
excerpt(text, width) = text.slice(clamp(delta, 0, max(0, len-width)), +width)
```

- **同一根游标**：阈值和窗口用同一个偏移量，不再另起一套。
- **起点不为负**：delta < 0 时起点夹到 0（没有「往前挪」的余量就停在开头）。
- **窗口宽度不变**：摘录长度仍受 `clip` 宽度约束，只挪起点不改长度。
- **同轮可复算**：给定实体与轮次，摘出来的片段唯一。

## 二、效果

| 轮次偏移 | 场景段摘到的内容 |
|---|---|
| delta 0 | 「帮我把季度报表里的异常项挑出来…」（从头） |
| delta +3 | 跳过前 3 字：「我把季度报表里的异常项挑出来…」 |
| delta -2 | 仍从头（不能越界） |

## 三、Acceptance Criteria

| # | 判据 |
|---|---|
| AC-1 | 同实体不同轮（delta 不同）摘录起点不同 |
| AC-2 | delta<0 起点为 0；delta>0 起点等于 delta |
| AC-3 | 摘录内容确为原文该位置起的子串 |
| AC-4 | 窗口宽度约束不变（超长加省略号） |
| AC-5 | 同一 (实体, 轮) 回单可复算 |
| AC-6 | 外部件仍不写库 |

## 四、边界

- 只挪**起点**，不挪长度、不改渲染。
- 无 round 传入时退化为 delta=0，与 6.34 行为一致（老调用无感）。
- 六段各自独立截取，偏移相同——不按段再散列。

## 五、仍开着的

1. 起点滑到中后段时，摘到的是句子中腰，可读性略降；要不要按句子边界对齐（找到最近的句号/逗号），待议。
2. 偏移量级的范围与阈值绑定；若阈值改口径，窗口会同步变。
