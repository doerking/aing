# SPEC-6.41 · 摘录起点对齐句读

> **一句话**：6.38 让摘录起点前后挪了，但偏移后常从句子中腰起（「把季度报表里的…」变成「表里的异常项…」）。现在起点就近吸附到句读之后。

## 一、口径

```
start0 = clamp(delta, 0, max(0, len-width))          // 6.38 原口径
start  = 就近吸附(start0)                              // 本 spec 新增
       = clamp(结果, 0, max(0, len-width))            // 吸附后再夹一次
```

### 1.1 吸附规则

- **句读集**：`。！？；，、：` 与换行。
- **搜索半径**：`SNAP = 12` 字（向前、向后各 12）。
- **就近**：前后都找到时取距离更近的；距离相同取**向后**（宁可少摘不丢内容）。
- **落点**：句读字符的**后一位**（摘录从新句子开头起）。
- **找不到就停**：半径内无句读 → 保持 `start0`，不乱跳。
- **段首不吸附**：`start0 = 0` 时本就从段首起，直接取原窗口。
- **宽度是上限**：吸附后窗口可以短于 `width`——宁可短一点，也不从中腰起。
- **仍加省略号**：截断处的 `…` 规则不变。

## 二、效果

| 原起点处 | 结果 |
|---|---|
| 「…我把季度报表里的异常项挑出来」起点落在「表里的」 | 吸附到最近的「，」之后 |
| 原文无标点（短句/数据串） | 起点不动，摘原窗口 |
| start0 = 0 | 本就从段首起，无需吸附 |

## 三、Acceptance Criteria

| # | 判据 |
|---|---|
| AC-1 | 起点落在句中 → 吸附到附近句读之后 |
| AC-2 | 前后都有句读 → 取更近的 |
| AC-3 | 半径内无句读 → 起点不动 |
| AC-4 | delta 越界先夹紧（<0 归 0、超出归 len-width）再吸附，窗口不超宽 |
| AC-5 | 窗口宽度是上限：未截断的部分不超过 width，截断处加省略号 |
| AC-6 | 同 (实体, 轮) 可复算 |
| AC-7 | 端到端：`externalPartNarrative` 摘录起点在段首或句读之后 |

## 四、边界

- 吸附只发生在 P1 外部件的摘录渲染（`tools/parasite-round.js`），不碰 kq、阈值、覆盖率。
- 句读集是可配常量；加新符号只改一处。
- 半径 12 字按经验定，无数据校准。

## 五、仍开着的

1. 长句无标点时仍会中腰起——要彻底解决得按词切或按摘要重写，属语义层。
2. 句读集不含英文句点（`.` 兼小数/缩写，误切风险高），英文原文暂不吸附。
