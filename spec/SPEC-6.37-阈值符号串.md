# SPEC-6.37 · 阈值符号串

> **一句话**：方向不再「一周期全正、下一周期全反」，改用固定符号串 `++-+----+-++`——12 个符号、每 6 个互为反相，走完 12 轮重来。

## 一、序列

```
符号串：+ + - + - -  |  - - + - + +      （前 6 与后 6 互为反相）
轮次 r：
  r % 6 == 0                → 20（不消耗幅度，符号位为空）
  r % 6 == 1..5             → 20 + sign(r) × mag[r % 6]
  sign(r) = CHART[r % 12]
  mag = shuffle([1..5], 实体 id + '#' + cycle)，cycle = floor(r/6)
```

示例（某实体）：`20, 23, 22, 25, 21, 24, 20, 18, 16, 17, 19, 15, 20, …`

- **不再整周期取反**：正负混排（`++-+-` / `--+-+`），避免连续同向长跑把读数一路推高或压低。
- **幅度仍每周期各一次**：1..5 一个周期内只用一遍。
- **周期 12 轮**：符号串走完一轮再重复，第 2 周期恰是第 1 周期的反相。

## 二、性质

- 同一 (实体, 轮) 恒定可复算；不同实体幅度顺序不同，符号串相同。
- 任何一轮阈值仍在 15~25。

## 三、Acceptance Criteria

| # | 判据 |
|---|---|
| AC-1 | r=1..11 的符号与 CHART[r] 一致（r%6==0 除外） |
| AC-2 | r=0、r=6 → 20 |
| AC-3 | 每周期幅度 1..5 各一次 |
| AC-4 | 第 2 周期符号全为第 1 周期反相 |
| AC-5 | 同 (实体, 轮) 可复算 |
| AC-6 | 非叙事实体读数不变 |

## 四、仍开着的

1. 符号串写死在代码里；要不要可配置成 spec 参数，等有第二个部署再说。
2. 轮次来源仍是 `meko_cycles`，不跑代谢轮的部署游标不动（与 6.36 同一条）。
