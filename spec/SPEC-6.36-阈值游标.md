# SPEC-6.36 · 阈值游标（20 → ±1..±5 → 20）

> **一句话**：6.35 只在 15/25 两档二选一；现在改成游标——20 出现一次，随后把 ±5、±4、±3、±2、±1 各用一遍（顺序随机），再回到 20，方向按周期交替。

## 一、序列

```
轮次 r → 阈值 (实体 e)：
  r % 6 == 0                     → 20
  r % 6 == 1..5                  → 20 ± m[r%6-1]
  m = shuffle([1,2,3,4,5], e + '#' + cycle)
  sign = cycle 偶数 ? +1 : -1     cycle = floor(r/6)
```

示例（某实体，正向周期）：`20, 23, 25, 21, 22, 24, 20, 18, 15, 19, 17, 16, 20, …`

- **每周期一次 20**：不连续贴着一个基准，让「刚好 20 字」有时过关、有时不过。
- **幅度用尽才回 20**：避免只在两端跳，中间幅度都被踩到。
- **方向交替**：正向周期走完，反向周期再走一遍。
- **随机=可复算**：shuffle 种子是「实体 id + 周期号」，同一实体同一轮永远得同一阈值，审计能复算。

## 二、实施位置

- `sectionThreshold(entityId, { round })`：round 缺省 0 → 阈值 20。
- `kespiStep` 用 `meko_cycles` 行数作轮次，逐实体传下去。
- 覆盖率与 kq 判定不变，只是门槛值会走。

## 三、Acceptance Criteria

| # | 判据 |
|---|---|
| AC-1 | 同一实体 round 0..11 的序列：每 6 轮首项为 20，其余 5 项幅度 1..5 各一次 |
| AC-2 | 同 (实体, 轮) 恒定，可重复计算 |
| AC-3 | 两实体同一周期 shuffle 顺序不同（多数情况） |
| AC-4 | 无 id 或无 round → 20 |
| AC-5 | 方向按周期交替（第 2 周期符号全反） |
| AC-6 | 非叙事实体读数不变 |

## 四、边界

- 阈值仍不进回单；接单方不知道本轮走哪档。
- 6.35 的「15/25 两档」口径由本条取代：任何一轮仍落在 15~25，但不再只有两端。

## 五、仍开着的

1. 轮次取 `meko_cycles` 行数——若某部署不跑代谢轮，轮次恒 0，阈值恒 20，游标不动。是否回退到按调用计数，待议。
2. 幅度集合固定 1..5；要扩到 1..7 或权重分布，是参数改动。
