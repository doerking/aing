# Evolver memory

EvoX keeps durable memory as **genes** (reusable approaches) and **capsules**
(worked examples). Use this skill when the user asks to remember, recall, or
inspect that memory.

## If `evolver` tools are in your tool list

- Recall before repeating a problem you may have already solved.
- Inspect before claiming the user has no saved assets.
- Solidify only after an approach actually worked. Do not invent genes.

## If those tools are not available

Tell the user to open EvoX → Settings → My agents and connect this agent.
Do not invent a memory store, write fake genes into the repo, or pretend a
save succeeded.
