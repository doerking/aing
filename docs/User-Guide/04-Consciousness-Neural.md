# 知识库会自己感知、思考、汇报

> 「意识神经」听着玄，其实就是三件事：它知道环境变了、它会排优先级、它会主动告诉你结论。

## 一句话

你不用问，它也会来报。像一个会自己巡逻、自己判断、自己写报告的管家。

## 三层，对号入座

```
🌿 末梢（感知层）  →  🔗 导链（路由层）  →  🧠 意识层（输出层）
   它发现变化            它决定谁优先            它把结论给你
```

| 层 | 它在干嘛 | 你熟悉的类比 |
|---|---|---|
| 🌿 末梢 | 轮询文件系统（每 5 秒），发现新/修改的 .md 文件 | 皮肤、眼睛、耳朵 |
| 🔗 导链 | 给每件事算注意力分、排优先级 | 神经、脊髓 |
| 🧠 意识 | 汇总 → 热点 / 告警 / 建议 | 大脑、嘴巴 |

## 🌿 末梢：它怎么"感知"

末梢（sensory-ends.js）每 5 秒轮询一次 `raw/` 目录，发现新文件或修改的文件就触发后续处理。

> 说明：当前实现是文件轮询，不是 chokidar 实时监听。

你不用写代码、不用点按钮，往目录里丢文件就等于"告诉它了"。

## 🔗 导链：它怎么"思考"

导链（neural-guide-chain.js）做一件事：算注意力分。

```
注意力 = 活跃度×0.3 + 最近度×0.25 + 连接密度×0.2 + 异常度×0.15 + 用户兴趣×0.1
```

分数高的进意识层处理，低的先搁着。它不会"什么都要"，这是它不崩的关键。

## 🧠 意识层：它怎么"汇报"

意识层（consciousness-layer.js）生成一份简报，包含：

| 输出 | 内容 |
|---|---|
| 热点 | 最活跃/最重要的实体 |
| 告警 | 需要关注的实体（低 KESPI、异常） |
| 建议 | 建议操作（发芽、授粉、压缩、剪枝） |

也就是说——有问题它告诉你，没问题它不吵你。

## 一个完整例子

你某天改了 `raw/AI-2026-01.md`，然后忘了。

1. **末梢**：5 秒后轮询发现文件变了
2. **导链**：算注意力分，排进处理队列
3. **意识层**：
   - 秩序脑把内容编译进 `wiki/`，更新图谱，Git 提交
   - 生长脑发现它跟「RAG vs 代谢」那篇能连上线 → 生成新链接
   - KESPI 跑完 → 0.87，绿灯，一切正常
4. **汇报**：什么都没说（因为没问题）

全程你只做了"改文件"一件事。

## 元认知层

元认知层（metacognition-layer.js）做三层自我反思：
1. **自检** — 验证自己的推理
2. **评估** — 评估输出质量
3. **调整** — 根据评估结果调整方法

## 三路突击

三路突击（tri-path-orchestrator.js）同时跑三条路径：
- **探索** — 发现新连接
- **验证** — 验证已有知识
- **优化** — 改进结构

带熔断器保护：失败 5 次后暂停 60 秒再试。

> ⚠️ 当前状态：`runPath()` 返回模拟数据，真实路径执行尚未实现。

## 对照一下

| 你担心的事 | 它怎么处理 |
|---|---|
| "我改了它不知道" | 末梢每 5 秒轮询，改了就触发 |
| "它会不会乱改" | Git 可回滚 |
| "忙起来没空看" | 绿灯不打扰，红灯才叫你 |
| "出问题查不到原因" | 错误日志记录在 error_log 表 |
| "想接别的系统" | 纯 MD 文件，任何工具都能读 |

## 小结

意识神经 = 感知（知道变了）+ 思考（排优先级）+ 汇报（主动说结论）。

不是玄学，是一套可观测、可扩展的工程机制。它让你从"天天盯着知识库"变成"只在它被红灯叫醒时才看一眼"。
