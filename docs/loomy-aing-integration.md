## 组件搭配表

| Loomy 组件 | aing 组件 | 搭配方式 | 积分消耗 |
|-----------|----------|---------|---------|
| **文件读写** | `compile.js` | 读 raw/ 写 wiki/ | 本地，零消耗 |
| **bash 执行** | `run-metabolism.js` | 跑 9 步代谢流水线 | 本地，零消耗 |
| **SQLite** | `knowledge-store.js` | 读写 knowledge.db | 本地，零消耗 |
| **记忆系统** | `会话入库` | 对话→raw/→compile→图谱 | 替代 Loomy 记忆，零消耗 |
| **网络搜索** | `auto-ingest.js` | 搜资料→入库→代谢 | 仅搜索扣积分 |
| **图片/多模态** | `raw/ 通道` | 外挂适配器→raw/ | 仅生图扣积分 |
| **飞书/企微** | `serve API` | agent 调 API 读写图谱 | 本地，零消耗 |
| **邮箱** | `神经末梢` | 感知外部信号 | 本地，零消耗 |
| **浏览器** | `auto-ingest` | 采集网页→入库 | 仅浏览扣积分 |

## 核心原则

> **能本地跑的不上网，能缓存的不重算，能代谢的不重编。**
> 
> aing 在 Loomy 里跑，只消耗 bash 执行和文件读写的积分，
> 不调 LLM API，不走网络，不额外扣费。
> 
> 这就是 aing 引擎在 Loomy 里的定位：**零附加成本的本地知识代谢层。**
