## 一、收口的两个洞

| 洞 | 收口前风险 | 收口后行为 | 落点 |
|---|---|---|---|
| ① 身份闸 | `POST /api/entity` 默认 `status:active` + `confidence:0.7`；`PATCH` 可翻 active、confidence 任意——外来者绕开 `distill.js` 兑付，未核验内容直挂知识资产身份进库 | POST 一律落 `pending-distillation`/`confidence:0`（客户端自报 status/confidence 忽略）；PATCH `status=active` → 403，confidence 不对外写；active 唯一写位 = `distill.js` | `src/api-server.js` |
| ② 标签闸 | 客户端自报 `distillation.tags` 任意字符串直入 `frontmatter.tags` 列，污染「标签=加载单位」+ 检索召回 + KA 资产化加权 | `auto-ingest` 客户端自报 tags 降级「## Agent 提议（未核验）」段引用行留痕、不升 DB 列；API entity 写面 tags 经 `sanitizeTags`（≤100字/≤20个/去控制字符） | `src/auto-ingest.js` + `src/api-server.js` |

同源性：洞①②是纪律 4（身份铁律）、纪律 7（标签是加载单位）、门禁 C10g③（自报不抬身份）在外来写面（HTTP API + 会话入库）上的落地。ingest 面早被 C10g③ 锁死（自报一律 pending-distillation/confidence 0），entity 直写面是并行的未锁侧门，本收口把它补齐。
