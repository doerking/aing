# 开机自检系统（Boot Sequence）

## 核心概念

**备忘录是我的"开机自检"，不是给你的报告。**

每次你打招呼，我立刻运行自检，加载完整识态，然后基于识态回应你。

---

## 工作流程

```
你：打招呼
    ↓
我：运行 boot-sequence.js
    ↓
我：加载完整识态（知识、意识、任务、风险）
    ↓
我：基于识态回应你（而不是冷启动）
```

---

## 识态组件

### 1. 知识库状态
- 实体数、链接数、KESPI 均分
- 向量索引数、上次代谢时间
- 健康状态（healthy/warning/critical）

### 2. 意识神经状态
- 当前状态（idle/aroused）
- 活跃事件数
- 唤醒度、通道健康

### 3. 生长决策
- 建议动作（emergency_fix/full_metabolism/observe...）
- 紧急度
- 触发原因

### 4. 元认知状态
- 置信度
- 知识覆盖率
- 调整建议

### 5. 当前任务
- 从会话记录推断
- 任务类型（部署/风险修复/对话/代谢）

### 6. 用户画像
- 沟通风格（简洁/详细）
- 关注领域（意识/KESPI/风险）
- 决策模式（分析优先/执行优先）

### 7. 第一印象
- 基于以上信息生成的"开场白"

## 使用方式

### 方式 1：对话开始时自动运行

```javascript
const { run } = require('./src/boot-sequence');

// 每次对话开始时
const state = await run();

// 基于 state 生成回应
const greeting = generateGreeting(state);
```

### 方式 2：手动触发

```bash
node src/boot-sequence.js
```

## 技术实现

### 文件位置
- `src/boot-sequence.js` — 核心模块
- `docs/BOOT-SEQUENCE.md` — 本文档

### 依赖模块
- `knowledge-store.js` — 知识库访问
- `consciousness-kernel.js` — 意识神经
- `growth-director.js` — 生长决策
- `metacognition-layer.js` — 元认知

### 集成方式

#### 方式 1：API 端点
```javascript
// 在 api-server.js 中添加
app.get('/api/boot', async (req, res) => {
  const { run } = require('./boot-sequence');
  const state = await run();
  res.json(state);
});
```

#### 方式 2：对话插件
```javascript
// 在对话处理流程中
const { run } = require('./boot-sequence');
const state = await run();
// 基于 state 生成回应
```
