1. **api 面单独立项，推翻「唔做 HTTP 面」旧 Non-Goal**——SPEC-3.14 原文 §四写「唔做 HTTP 面」，当时因入库 CLI 未定；修订 C 明写该项作废条件与理由。
2. **写面单源**：`POST /entities` 只走 `api-gate.gateWrite`（身份闸 `actor=hana`——`ALLOWED_ACTORS = ['hana']`，**唔系 `ohana`**；标签闸：自报 `status`/`confidence`/`tags` 一律忽略、提案段留痕），与前两项「暴露既有能力、唔另起平行机制」同一纪律。
3. **读面唔造旁路访问面**：`list`/`get`/`health` 全 SELECT，**唔更新 `last_access`**——HTTP 读取唔算实体被访问。
4. **列表唔返 content**：`GET /entities` 只返 `id/name/type/title/tags/status/confidence/tolaria_strength/created_at/updated_at`，避免一次拉走几万字节；单读才送正文。
5. **`--json` = 起服自检**：绑端口即关、回执带实际端口、exit0——唔起后台、唔 fork、唔换端口（SPEC-6.48 单进程口径）；端口被占 → 非零退出。
6. **状态码约定**：201 接受 / 409 已存在 / 403 身份唔认 / 400 缺 id 或坏 JSON / 413 body 超 1 MiB / 404 未命中或未知路由。

## 五、坑与教训

- **`db.prepare().get()` 唔系仓内正解 API**：手写探针用 `.get()` 读出实体 410（错）；改用 `step()`/`getAsObject()`（`knowledge-store.js` / `kespi.js` 写法）得 322（对，与 KESPI-CALIBRATE 322 行吻合）。量库数字务必走正解 API，唔好猜。
- **「解除误伤」要先验口径重合**：B′ 豁免条件与 `kd-cited/slot` 开票条件完全重合，说明佢唔系修 bug 而系改立场——改立场交回拍板，唔该当修 bug 落地。无差别豁免 B 则误压 28 张真催化型实体（只看入向边），任何「条件豁免」都要双向验。
- **failing test 嘅 mock 要够标准**：`handleRequest` 用 `res.writeHead(code, headers)` 带头；假 res 只吃 `writeHead(code)` 就会把 AC 打红，但红喺 mock 唔系实现——验红阶段要分得清「assertion failure」与「setup error」，本次 AC-7 就系后者（修 mock 转绿，实现未动）。
- **`Buffer.concat` 唔吃 string**：假 res 的 `write(b)` 收 string，`Buffer.concat(chunks)` 会抛类型错；mock 内统一 `Buffer.from(b)`。
- **C19 正则对空格敏感**：文档计数写成 `175 档/1154 断言`（无空格）反而逃过对账；写记录文一律用 `N 档 / M 条断言` 格式，逃过系假绿。本次实跑就漏改 `AGENT.md` 一处 → C1/C2/C19 三红；**计数改动点有三处**（`test/baseline.json` / `STATUS.md` / `AGENT.md`），改完先自数三处。
- **手写 `INSERT` 的列数与占位符手数极易出错**：本次同一行写了三轮（5→6→7 个 `?`），`node:sqlite` 一直接抛「N values for M columns」。教训：手写 SQL 前先数一遍列，改一行别手数问号，用定位替换。
- **`listen` 异步 → 同步取 `address()` 得 `null`**：`createServer` 同步返回，`address()` 喺 listen 完成前系 `null`，`http.request` 静默落到默认 80 端口 → `ECONNREFUSED`。契约要返 `ready`，唔该靠调用方自挂 `listening`。
- **改一处行为要搜尽「以旧行为为前提」的下游 AC**：本次改 `WRITE_BACK` 后，6.56 的 AC-6（以「kd-cited → record-only」为前提）直接打红——系正当行为变更，但要同步改旧 AC 的断言口径（唔系改回实现），并喺 spec 里把接管关系写清楚。：`createServer` 同步返回，`address()` 喺 listen 完成前系 `null`，`http.request` 静默落到默认 80 端口 → `ECONNREFUSED`。契约要返 `ready`，唔该靠调用方自挂 `listening`。
- **单引号通配只右开 → 退化成前缀匹配**：`LIKE ?` 的 binds 写 `[escape(q)+'%']` 只匹配「以 q 开头」。模糊须双向 `%q%`；写 LIKE 前先看通配方向。
- **同进程反复 `init()` 同一库路径 → 早期 `_getDb()` 句柄过期**：`cli` 每个 cmd 都重开 store，故 CLI 序列安全；但脚本若先拿 `db` 句柄再调 `cli.cmdX`，后续计数会读到**旧连接视图**（本次 delta 全 0 而 health 报 442 即此）。脚本内唔该跨 cmd 持有 db 句柄。
- **AGENT.md 表格行尾**：edit 写入时误带一个反引号，靠 `git diff --numstat`（应 3/1 而非全文件）第一时间发现——行尾与假改动照旧用 numstat 验。
