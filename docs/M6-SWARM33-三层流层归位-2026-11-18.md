# swarm33 六模块断言 → 三层流层归位（2026-11-18）

> **口径来源**：STATUS §七 **D17**（owner 2026-11-18）——swarm33 属 **DNA 范式 0.5 版**：`aing →（信号）→ memo（单向）→ meko → 直接派单至 skill 或寄生 → meko 跟单 → 回单 → meko 外接屏显示 → 处理单次`。
> **本件做什么**：六模块 **134 条断言**（`grep ok(` 报 135，多出的一处是 `ok` 函数定义本身）逐段归位到五层，每条给「留 / 改 / 弃」。
> **本件不做什么**：不搬代码。六件源码本身不接进新构造（D17），只取口径。

## 一、五层定义

| 层 | 含义 | 对应 v2 现状 |
|---|---|---|
| **L1 信号层** | aing 产生信号：KESPI/代谢读数、缺口、蒸馏点、轨迹 | `kespi.js` / `gap-scan.js` / `distill-points.js` / `trajectory.js` |
| **L2 memo 阀门** | 单向：只出读数与派单卡，不执行 | `memo.js`（SPEC-2.18 / D12） |
| **L3 meko 派单/跟单** | 派单至 skill/寄生；跟单（心跳、补位、失败改派） | `self-optimize.js` / `meko-field.js` / `dispatch-card.js` |
| **L4 回单与外接屏** | 回单只带事实+指针；外接屏显示前过发布闸 | **缺**——`opt_tickets.verified` 只记状态，无内容闸 |
| **L5 单次处理** | 同单只处理一次；产物一次加标签 | SPEC-7.1 AC-15 `metabolized_at` |

**最值钱的三条（建议优先落实现）**：
1. **膜透性三档**（core §6）——回单只过事实+指针，全文与结论一律拦。正对现在自优化环「工单无内容闸」的缺口。
2. **发布门**（combat §4）——缺事实 / 缺真跑证据 / 缺来源分级 / 缺自评 / 弱证据一律不发布，与判断成文模板六条红线同源。
3. **追单不补位**（org §4）——回单未落盘先追单、同单失败≥2 改派、无预备则上报；这是跟单层唯一能防「假跟单」的硬规则。

**术语红线**：以下内部词不得进发布包，归位实现时一律换工程词——弹道（→ 回单/结果落盘）、波次（→ 批次）、场域渗透（→ 介质面）、麦当华·派发人·营长·班长·单元长（→ 拍板方/派单方/跟单方/执行点）、三三制（→ 三级分工）。
