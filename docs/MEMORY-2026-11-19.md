## 二、这一段定下的口径（都进了 spec）

1. **kq 对叙事 = 原三项权重 × 覆盖率乘子**（`0.6 + 0.4×覆盖率`）；覆盖率为 0 时压到 ×0.6，不归零。
2. **段有效性**：段正文去空白不足门槛不算「有这一段」；门槛走游标，基准 20。
3. **阈值游标**：每周期首轮 20，随后幅度 1..5 各一次（shuffle 种子＝实体 id＋周期号），方向按符号串 `++-+----+-++`（12 轮循环，前后 6 守互反）。
4. **叙事 kq 长度只量六段正文**：段外填充不进长度分。
5. **kq 工单分流**：叙事实体走 `kq-low-narrative`（P1/full，want 明写六段齐全每段 ≥ 门槛）；非叙事仍 P2/semi。
6. **P1 全寄生一轮**：外部件只读单与原料，回单六段由系统 `applyReturnNarrative` 写回——只换 markdown 与 bodyChars，`turns` 保留，打 `narrative{P1,full,provided}` 标。
7. **六段抽取＝骨架恒定＋事实槽滑动**：场景/思维/手段/编排/产出/校准逐段取实体轨迹；无证据的段只写声明，覆盖率如实下降。
8. **摘录窗口滑动**：摘录起点 = 阈值偏移（0 或 ±1..±5 字），夹在 `[0, len-width]`。
