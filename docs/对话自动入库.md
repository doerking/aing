# 对话自动入库 / Conversation Auto-Ingest

> 让 Agent 的每轮对话自动成为知识库的一部分。

## 一句话

对话即知识。Agent 与用户的每轮对话自动入库、编译、检索，全程留痕。

## 快速开始

### 1. 基本使用

```javascript
const { AgentAutoIngest } = require('./src/agent-auto-ingest');

const ingest = new AgentAutoIngest({
  agentId: 'hermes',
  minMessageLength: 20,
});

// 入库单条消息
ingest.入库({ role: 'user', content: '今天天气怎么样？' });

// 入库完整对话
ingest.入库对话([
  { role: 'user', content: '有什么推荐？' },
  { role: 'assistant', content: '推荐去公园散步。' },
]);
```

### 2. CLI 模式

```bash
# 单次入库
echo '{"role":"user","content":"测试消息"}' | node src/agent-auto-ingest.js --agent hermes

# 持续监听
node src/对话自动入库.js --listen
```

### 3. 管道输入

```bash
# 从文件或管道读取 JSON 消息
cat messages.json | node src/agent-auto-ingest.js
```

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `agentId` | `default-agent` | 代理 ID |
| `sessionId` | 自动生成 | 会话 ID |
| `kbRoot` | 当前目录 | 知识库根目录 |
| `minMessageLength` | 20 | 最小消息长度 |
| `maxMessagesPerBatch` | 10 | 每批最多消息数 |
| `batchIntervalMs` | 5000 | 批处理间隔（毫秒） |
| `autoCompile` | `true` | 入库后自动编译 |

## 入库流程

```
Agent 消息 (>=20字符)
    ↓
SessionStore 收集
    ↓
[每 10 条 OR 每 5 秒] 触发入库
    ↓
生成 Markdown 文件 → raw/
    ↓
compile.js 编译 → wiki/
    ↓
import → SQLite DB
    ↓
vector index → 语义可搜
```

## 内容格式

入库文件示例（`raw/session-xxx-2026-09-08.md`）：

```markdown
---
name: session-xxx-2026-09-08
type: Conversation
tags:
  - aing
  - deployment
status: active
confidence: 0.9
source: hermes-session
created: 2026-09-08T17:52:00+08:00
messageCount: 5
---

# session-xxx-2026-09-08

## 原始消息
用户：今天天气怎么样？
助手：根据最新气象数据，今天晴天，气温 25-30 度。

## 提取实体
- [[公园]]
- [[天气]]

## 标签
[tag:aining] [tag:conversation]
```

## 去重机制

- **内容指纹**：SHA1 哈希去重，同内容不重复入库
- **会话隔离**：每个会话独立存储，避免交叉污染
- **账本持久化**：已入库指纹写入 `data/ingest-hashes.json`

## 实际应用

### 集成到 Agent 循环

```javascript
class 我的 Agent {
  constructor() {
    this.入库 = new AgentAutoIngest({ agentId: 'my-agent' });
  }
  
  async 处理用户消息 (消息) {
    // 1. 入库用户消息
    this.入库.入库({ role: 'user', content: 消息 });
    
    // 2. 处理消息
    const 回复 = await this.生成回复 (消息);
    
    // 3. 入库助手回复
    this.入库.入库({ role: 'assistant', content: 回复 });
    
    return 回复;
  }
}
```

## 故障排查

| 症状 | 原因 | 处置 |
|------|------|------|
| 消息未入库 | 长度 < 20 字符 | 调整 `minMessageLength` |
| 重复入库 | 去重账本损坏 | 删除 `data/ingest-hashes.json` |
| 编译失败 | raw/ 文件格式错误 | 检查 YAML frontmatter |
| 内存泄漏 | 会话未清理 | 定期清理 `sessions` Map |

## 性能优化

- **批量入库**：每 10 条消息批量处理，减少 I/O
- **异步编译**：编译在后台执行，不阻塞入库
- **压缩账本**：保留最近 5000 条指纹，避免无限增长
