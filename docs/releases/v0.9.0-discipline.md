## aing v0.9.0 — Discipline（纪律版）

aing 的第一个里程碑版本：一个**知识代谢引擎**——知识库自己生长、自己质检、自己防腐烂，全程零 LLM 依赖核心循环（LLM 仅为可选宿主外壳）。

### 本版本主题：纪律

「每一条声明都有证据，没有 ALL GREEN 就等于部署未完成。」本版本把这句话变成可执行的验收体系。

### 亮点

- **一键验收器 `verify-deploy.js`**：C0–C7b 十道质量门（Node 运行时 / 配置唯一来源 / 依赖三件套 / raw 种子 / 数据库完整性 / 本地语义模型 / 语义检索冒烟 / KESPI 生命周期一致性 / 补丁层指纹；后续版本追加 C8 盘符字面量扫描），逐项给修复指引，无 ALL GREEN 即 exit 1
- **KESPI 八维自检**：质量/生长/资产化/代谢/密度/检索/回答/阻断加权评分，三色灯（🟢≥0.80 自主运行 / 🟡≥0.65 自动修复 / 🔴<0.65 人工干预），评分入 kespi_history 可审计
- **蒸馏可审计**：sha1 内容指纹 + 逐条可追溯 + `--dry-run`，摘要可验证非编造；入库路径无蒸馏债（self-test 覆盖）
- **双脑双写**：wiki 文件 + SQLite 双源可对账，原子锁范式贯穿（wx + finally + 陈旧回收）
- **三路突击蜂群**：探索/验证/优化并行 + 队正裁决 + 熔断保护（阈值唯一来源 growth.config）
- **本地语义检索**：384 维离线模型（Xenova/all-MiniLM-L6-v2，约 12MB 不入库，`setup-vectors.ps1` 一键装），未就位自动回退 64 维哈希
- **常驻服务**：scheduler 定时代谢 + raw/ 轮询触发；API server 零依赖 HTTP + Bearer 认证 + 租户会话隔离
- **文档脱敏**：全部文档/注释层硬编码盘符已替换为语义占位符（`<repo-root>` 等），外来残留清零

### 安装

```bash
git clone https://github.com/doerking/aing.git
cd aing
npm install
npm run bootstrap        # 一键：建库 → 代谢链 → 语义模型 → 验收（v0.9.0 时点请按下方"注意"分步执行）
node verify-deploy.js    # 看到 ALL GREEN 才算部署完成
```

> **注意（v0.9.0 时点）**：`npm run bootstrap` 为后续版本引入；本版本请分步执行：
> `npm run setup:db` → `npm run metabolism`（或 `node src/run-metabolism.js`）→ `npm run setup:vectors` → `npm run reindex:semantic` → `node verify-deploy.js`

### 快速体验

```bash
node src/query.js "KESPI" --limit 5     # 三路融合检索，输出分构成
npm run scheduler                        # 常驻代谢（默认 30 分钟一轮）
npm run server                           # HTTP API（默认 127.0.0.1:3789）
```

### 已知边界（如实声明）

- 种子期数据库仅 8 实体（raw/ 8 篇文档编译所得），检索质量随真实使用增长
- 干净 clone 首跑 verify-deploy 的 C5/C6 会红——属预期，先跑 `setup-vectors.ps1` 装模型
- 意识/元认知组件在库：consciousness 为协调内核（事件已接线），metacognition 尚未接入管线（Phase 2.6）
- 权重参数（KESPI 八维 / 查询融合）为经验值，标定工具在后续版本提供
