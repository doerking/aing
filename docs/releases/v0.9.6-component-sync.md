`jest.config.js` + `tests/unit/`（11 个测试）**在库但未接管线**：`jest` 未声明在 `package.json`（dependencies 仅 transformers/js-yaml/sharp/sql.js，无 devDependencies 段）、无 npm script 入口、`verify-deploy` / `self-test` 均不消费本面。收包方需自备 jest 方可跑（`npm i -D jest && npx jest`）。
