# Release v0.9.8 — 编程技能库撤回 & 门禁面校准 / Skill Library Revert & Gate Re-calibration

> 发布对象：`v0.9.7`（a75c651）之后的撤回提交 ｜ 起草：2026-11-09 ｜ 状态：**推送中**

## 背景：一次入仓决策的回撤

v0.9.7 批次（`3f20b4b`）把 `F:\编程技能库`（17 技能 1104 件）复制进 `assets/skills/编程技能库`，当「bundled 技能资产」随包走。事后厘清定位：

> 编程技能库系**纯整理产物**——源料落 `G:\DPD\编程技能库\`，非 aing 主线能力资产、非 aing 待补项。它唔该占 aing 发布包的资产面。

故本版本把该目录**整条撤回**（`git rm -r`），主仓只留真正自撰嘅技能资产（`neural-evolution-swarm` + `aing-operator`）。
