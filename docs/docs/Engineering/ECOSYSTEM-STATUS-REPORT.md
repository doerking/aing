## 四、KESPI 分布

| 区间 | 说明 |
|------|------|
| 🟢 ≥0.80 | 绿灯：系统自动运行 |
| 🟡 ≥0.65 | 黄灯：生成优化任务 |
| 🔴 <0.65 | 红灯：人工干预 |

**KESPI 维度**: 8维加权（KQ/KG/KA/KM/KD/KC/KR/KB）+ 5维增强（originality/relevance/consistency/provability/utility）
**存储**: 8维分数写入 `kespi_history.dimension_scores`（JSON），综合分写入 `entity_metadata.kespi_score`
