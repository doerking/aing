## 四、市场定位

### 4.1 现有产品格局

```
                   高自动化
                      │
                      │      aing（代谢引擎）
                      │         ↑
          LLM Wiki 生态 │
          (Sage-Wiki/  │
          Graphify)    │
                      │
  低功能深度 ─────────┼────────── 高功能深度
                      │
        Mem.ai │      │
        Notion AI     │  Obsidian
                      │  Logseq
                      │
                   低自动化
```

### 4.2 aing 的独特定位

**唯一具备"代谢层"的知识引擎**。市场上所有产品——无论是商业的 Notion/Mem，还是开源的 Sage-Wiki/Graphify——都停留在"存储-检索"范式，最多做到"自动编译"。aing 是唯一一个实现了"发芽-授粉-压缩-健康检查-衰减-再生"全代谢链条的。

### 4.3 关键差异化

| 维度 | 竞品 | aing |
|------|------|------|
| 知识增长 | 线性：存→查 | 非线性：自生长 |
| 自动化 | 编译/搜索 | 编译+代谢+感知+认知 |
| 数据主权 | 云端/厂商锁定 | 本地 Markdown，永远可读 |
| 依赖 | 需要 LLM API / Docker | 零依赖，纯 Node.js |
| 价格 | $10-30/月 | 免费，MIT 开源 |
| 扩展性 | 加功能加钱 | 加 agent 不加成本 |

## 六、一句话总结

> **aing 是目前唯一实现了"知识代谢"——而不仅仅是"知识编译"——的开源引擎。**
> 
> 市场上有 Obsidian（存储好）、有 Sage-Wiki（编译好）、有 Notion AI（搜索好），
> 但**没有一款产品能让知识自己发芽、授粉、压缩、健康检查、衰减再生**。
> 
> aing 填补了这个空白。工程等级 B+，核心代谢能力独一无二。
> 补齐 HTTP API 和中文支持后，即可达到 A- 级，具备商业级竞争力。
